# Autoria e propriedade intelectual

## Autoria principal

O PSF-IAminy-Open é um projeto do **Pensador Sem Fronteiras**, publicado pelo
perfil **Progaminy**, que consta como autor principal no `pyproject.toml` e no
`CITATION.cff`.

Contribuições futuras permanecem identificáveis pelo histórico Git e pelos
pull requests. Este documento não transfere direitos sobre contribuições nem
substitui os termos da licença.

## Como citar

Use os metadados de `CITATION.cff`. Enquanto não existir uma release publicada
e arquivada com identificador persistente, a citação deve incluir a URL do
repositório e o commit consultado. Não invente DOI, instituição, revisão por
