# Public roadmap

This is an English translation of the canonical Portuguese
[public roadmap](../../ROADMAP.md). The detailed scientific and technical
history remains in `PLANO_PSF_IAMINY.md`. The priorities below are not schedule
commitments.

## Now

- obtain the first green public CI run;
- complete the documentation-coherence audit;
- prepare and publish `v0.1.0 — Public Research Preview`;
- test installation and the demonstration in a clean environment.

## Next

- classify tests as unit, integration, regression, interface and scientific
  evidence;
- identify critical modules below the desired coverage;
- create reproducible time and memory benchmarks;
- document dependencies, compatibility and governance;
- publish an English README and translate essential documents.

## Later

- validate mathematical and linguistic results against external references
  while keeping those tools outside the PSF foundation;
- publish a report of agreements, divergences and corrections;
- test on other operating systems and environment versions;
- prepare real static documentation, images and a short demonstration;
- collect reproduction reports, feedback and contributions from external
  users.

## Under investigation

- mathematical frontiers beyond the finite domain already constructed;
- limits of variation, context and community in Portuguese;
- falsification of the level-division primality hypothesis;
- objective criteria for scientific quality and public usefulness.

A capability advances to implemented only when it has code, tests,
documentation, edge cases and declared limitations, without contradicting the
project's integrity rules.
